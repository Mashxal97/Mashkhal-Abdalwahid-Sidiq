# Portfolio one-pager

A single self-contained `index.html` — no build step, no dependencies beyond a Google Fonts
stylesheet. Content is taken from the CV; edit the HTML directly to keep it current.

To host it free at `https://mashxal97.github.io/Mashkhal-Abdalwahid-Sidiq/portfolio/`:
Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)`.
